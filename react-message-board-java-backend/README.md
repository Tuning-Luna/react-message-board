
# 留言板系统 (GuestbookSystem)

## 项目简介

这是一个基于微服务架构的现代化留言板系统，支持用户留言、点赞、管理员回复等核心功能。系统采用前后端分离设计，后端使用Spring Cloud微服务架构实现，具备良好的扩展性和可维护性。

## 技术栈

### 核心框架
- **Spring Boot 2.7.12**: 应用基础框架，提供自动配置和依赖管理
- **Spring Cloud 2021.0.3**: 微服务生态系统框架
- **Spring Cloud Alibaba 2021.0.4.0**: 提供Nacos等微服务组件

### 数据持久层
- **MyBatis-Plus 3.5.3.1**: 增强型ORM框架，简化数据库操作
- **MySQL**: 关系型数据库

### 微服务组件
- **Nacos**: 服务注册与发现、配置中心
- **Spring Cloud Gateway**: API网关，处理请求路由和过滤
- **OpenFeign**: 声明式REST客户端，简化服务间通信
- **LoadBalancer**: 客户端负载均衡

### 安全与认证
- **JWT (JSON Web Token)**: 实现无状态认证
- **Spring Security**: 安全框架，提供认证和授权功能

### 工具库
- **Hutool 5.8.11**: Java工具集，提供常用功能封装
- **Lombok**: 简化Java代码，减少模板代码
- **Jakarta Validation API**: 参数校验框架

### 开发环境
- **JDK 11**: Java开发工具包
- **Maven**: 项目管理和依赖构建工具

## 项目结构

```
GuestbookSystem/
├── guestbook-api/          # API定义模块，包含接口、DTO、VO等
├── admin-service/          # 管理员服务模块
├── user-service/           # 用户服务模块
├── guestbook-gateway/      # API网关模块
├── guestbook-common/       # 通用模块，包含公共依赖和工具类
└── pom.xml                 # 父项目配置文件
```

### 模块职责

1. **guestbook-api**
    - 定义服务间通信接口（Feign Client）
    - 数据传输对象（DTO）和视图对象（VO）定义
    - 公共工具类和异常定义

2. **user-service**
    - 处理用户留言的增删改查
    - 实现留言点赞功能
    - 提供留言搜索和分页排序功能

3. **admin-service**
    - 管理员登录认证
    - 留言管理和回复功能
    - 邮件服务集成

4. **guestbook-gateway**
    - 请求路由转发
    - 认证授权过滤
    - 跨域处理

5. **guestbook-common**
    - 数据库连接和MyBatis配置
    - 公共依赖管理

## 系统架构设计

### 分层架构

系统采用典型的分层架构设计：

1. **表示层 (Controller)**：处理HTTP请求，调用服务层并返回响应
2. **业务层 (Service)**：实现核心业务逻辑
3. **数据访问层 (Mapper)**：与数据库交互
4. **API定义层**：定义服务间接口规范

### 微服务通信

- **同步通信**：使用OpenFeign进行服务间REST调用
- **异步通信**：支持通过消息队列实现（可扩展）

### 认证授权流程

1. 用户/管理员登录获取JWT令牌
2. 请求携带令牌访问受保护资源
3. 网关层验证令牌有效性
4. 服务层提取用户信息进行权限控制

## 核心功能实现

### 1. 留言管理

- **留言查询**：支持分页、关键词搜索和排序（最新/最热）
- **留言发布**：用户提交留言信息并保存到数据库
- **留言删除**：管理员可以删除留言，包含数据校验和异常处理
- **留言详情**：查看单条留言及其所有回复

### 2. 点赞功能

- 实现对留言的点赞功能，自动增加点赞计数
- 包含消息存在性验证，避免无效操作

### 3. 管理员回复

- 管理员可以对用户留言进行回复
- 回复信息与原留言关联存储
- 支持多回复展示

### 4. 搜索与排序

- **关键词搜索**：支持按标题、内容、昵称和回复内容进行搜索
- **智能排序**：支持按创建时间（newest）和点赞数（mostLiked）排序
- **空关键词处理**：当关键词为空时返回所有留言

### 5. 分页功能

- 基于PageParam参数实现分页查询
- 返回完整的分页信息（总数、当前页、页大小、数据列表）

## 系统亮点

### 1. 微服务架构

采用Spring Cloud微服务架构，各服务职责明确，易于扩展和维护。使用Nacos实现服务注册发现，Gateway处理统一入口。

### 2. 健壮的异常处理

系统实现了完善的异常捕获和处理机制，包括：
- 参数校验异常处理
- 业务逻辑异常处理
- 系统级异常处理
- 友好的错误提示

### 3. 高效的数据查询

通过MyBatis-Plus实现高效的数据访问，采用多种优化手段：
- 使用Lambda表达式构建查询条件
- 合理的索引设计
- 避免N+1查询问题
- 批量数据处理

### 4. 灵活的排序机制

实现了基于用户选择的动态排序功能，支持多种排序方式，并可根据需求轻松扩展。

### 5. 安全的认证机制

使用JWT实现无状态认证，确保API安全访问：
- 基于非对称加密的令牌生成和验证
- 令牌有效期管理
- 权限控制和资源访问限制

## 设计思路

### 1. 领域驱动设计

系统设计遵循领域驱动设计思想，按功能模块划分服务，确保服务内聚性：
- 用户服务专注于用户留言的管理
- 管理员服务专注于系统管理功能
- API模块定义公共接口和数据结构

### 2. 关注点分离

通过清晰的分层和模块划分，实现关注点分离：
- 表示层专注于请求处理和响应格式化
- 业务层专注于业务逻辑实现
- 数据访问层专注于数据持久化

### 3. 可扩展性考虑

- 使用接口定义服务契约，便于未来实现替换
- 采用配置驱动设计，支持环境差异化配置
- 服务无状态设计，支持水平扩展

### 4. 性能优化

- 实现分页查询，避免大数据量一次性加载
- 合理使用缓存（可扩展）
- 优化数据库查询，避免全表扫描
- 批量操作减少数据库交互

## 部署与运行

### 环境要求

- JDK 11+
- MySQL 5.7+
- Nacos 2.0+

### 启动顺序

1. 启动Nacos服务
2. 启动各个微服务（guestbook-common、guestbook-api、admin-service、user-service）
3. 启动网关服务（guestbook-gateway）

### 访问入口

- 系统API入口：http://localhost:8080
- 用户留言列表：http://localhost:8080/api/messages
- 管理员登录：http://localhost:8080/api/admin/login
